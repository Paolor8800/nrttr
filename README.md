# Узнай друзей 🎤

Весёлая вечериночная игра для компании из 3–16 человек. Переделана из карточной
игры «Cringe-o-rama». **Сетевой слой (WebSocket + HTTP + сессии и переподключение)
оставлен без изменений** — переписана только игровая логика и интерфейс.

## Как играть

1. Каждый игрок при создании/входе в комнату вводит **имя** и выбирает **пол**
   (мужской / женский).
2. Ход переходит от игрока к игроку (как и раньше) — по очереди каждый становится
   **ведущим**.
3. На экране у всех появляется случайный вопрос про ведущего, окончания которого
   подстроены под его пол. Например, для Насти: «Чем Настя обычно занимается, когда
   остаётся дома **одна**?», для Димы — «…дома **один**?».
4. Игроки пишут свои версии ответа, а ведущий пишет **правильный** ответ.
5. Когда ответили все, ответы игроков показываются **анонимно и в случайном порядке**,
   а правильный ответ ведущего — отдельно.
6. Ведущий выбирает **самый правильный** ответ и пытается **угадать автора** каждого
   ответа. Остальные игроки голосуют за **самый смешной** ответ (при ничьей он
   выбирается случайно).
7. Ведущий нажимает «Завершить раунд» — баллы начисляются. **Авторство ответов не раскрывается.**
8. Ход переходит к следующему игроку, круг за кругом, пока кто-то не наберёт
   **35 баллов** — тогда итоговая таблица.

## Что изменено

### Сервер (игровая логика — переписана)
- `server/shared-types.ts` — новая модель состояния (`GameState`, фазы
  `answering | judging | roundResults | gameOver`, `PlayerAction`, `Gender`).
- `server/shared-events.ts` — новые игровые события.
- `server/shared-handlers.ts` — чистые функции: перемешивание, анонимизация
  ответов, подсчёт очков, выбор победителя.
- `server/room.ts` — **вся сессионно-сетевая часть сохранена дословно**; переписаны
  только игровые методы (`startGame`, `processAction`, раунды). Авторство ответов
  хранится в приватном поле комнаты и **никогда не рассылается** клиентам.
- `src/data/questions.ts` — **банк вопросов** (исправлены ошибки, расставлены теги
  пола, добавлена авто-адаптация окончаний через токены `{м|ж}` и `{name}`).

### Сеть (НЕ тронута, только проброшен пол как данные)
- `server/index.ts` — добавлена передача `gender` в `addOrUpdatePlayer` (HTTP и WS).
- `server/protocol.ts` — `gender` добавлен в `LobbyPlayer` и сообщение `identify`.

### Клиент
- `src/pages/Index.tsx` — выбор пола при входе/создании комнаты (♂/♀), бренд «Узнай друзей».
- `src/hooks/useGameRoom.ts` — `gender` отправляется в `identify` (HTTP + WS). Удалена
  карточная логика `collectUsedCards`.
- `src/types/game.ts` — клиентская модель состояния (зеркало серверной).
- `src/pages/GameRoom.tsx` — **новый экран**: лобби + 4 фазы игры.
- Удалены файлы старой карточной игры (колоды, дуэли, ставки, кринж-ревил и т.п.).

## Запуск

```bash
npm install      # установить зависимости (node_modules в архив не входит)
npm run dev      # клиент (Vite)
npm run dev:server   # игровой сервер (порт 8080)
```

## Подсчёт очков (кратко)

| Событие                                   | Кому     | Баллы |
|-------------------------------------------|----------|-------|
| Ведущий выбрал ответ «самым правильным»   | автору   | +2    |
| Игроки выбрали ответ «самым смешным»      | автору   | +2    |
| Ведущий угадал автора ответа              | ведущему | +1 за каждого |

## Казино

- Ставка — 1 очко, крутить можно, если есть хотя бы 1 очко (после финала казино закрыто).
- Выигрыш: красное/чёрное **+2**, конкретное число **+4**, зеро **+6**; проигрыш **−1**.
- Начиная с **32 очков** (и до победных 35) следующие **5 ставок подряд проигрывают** —
  казино не должно решать финал. На игрока, который уже набрал 35 в раундах, это
  правило не действует. Порог — `CASINO_FORCED_LOSS_FROM_SCORE` в `server/room.ts`.
- Между ставками одного игрока сервер выдерживает 5 секунд (колесо крутится 7,6 с),
  а ставка без связи не откладывается «на потом» — её надо сделать заново.


## Деплой на Railway

Игра — **единый сервис**: сервер раздаёт собранный клиент (`dist/`) и держит
WebSocket/HTTP на одном порту, слушает `process.env.PORT` на `0.0.0.0`.

Файлы конфигурации уже добавлены: `railway.json`, `nixpacks.toml`, `.node-version`.

### Шаги
1. Создай новый проект на Railway → **Deploy from GitHub repo** (или `railway up` через CLI).
2. Railway сам подхватит `railway.json`:
   - Build: `npm run build` (Vite-клиент + компиляция сервера в `server-dist/`)
   - Start: `npm run start` (`node server-dist/server/index.js`)
   - Healthcheck: `GET /api/health`
3. Переменные окружения **не обязательны** — порт Railway передаёт автоматически
   через `PORT`. Клиент по умолчанию подключается к тому же origin
   (`window.location.origin`, для https → `wss:`).
4. В разделе **Settings → Networking** нажми **Generate Domain**, чтобы получить
   публичный адрес.

### Опционально
- Если когда-нибудь захочешь развести клиент и сервер на разные домены — задай на
  фронте переменную `VITE_SERVER_URL` (на этапе сборки) с адресом сервера.

## Большие компании (13–16 игроков)

- Лимит комнаты — 16 игроков (`MAX_PLAYERS` в `src/lib/roomLimits.ts`, общий для сервера и клиента).
- Игрок, который не в сети дольше 30 секунд, больше не задерживает ответы и голосование;
  когда он вернётся, его снова ждут. Ведущий, пропавший дольше 60 секунд, теряет ход —
  раунд начинается со следующим игроком. Если на экране итогов пропали и ведущий, и хост,
  продолжить может любой игрок. Пороги меняются переменными окружения сервера
  `PLAYER_AWAY_GRACE_MS` и `LEADER_AWAY_GRACE_MS`.
- Нагрузочный прогон: 15 ботов играют несколько раундов, один из них обрывает связь и
  переподключается, другой пропадает насовсем.

  ```bash
  npm run build
  PLAYER_AWAY_GRACE_MS=3000 LEADER_AWAY_GRACE_MS=6000 npm run start
  npm run test:load -- --players 15 --rounds 3 --chaos   # в другом терминале
  ```

## Условия победы

- Игра идёт круг за кругом, пока кто-то не наберёт **35 баллов** (`TARGET_SCORE` в
  `server/room.ts`). Итог подводится, когда ведущий или хост нажимает «К финалу»
  на экране итогов раунда.
- Побеждает игрок с наибольшим счётом. Если у лидеров счёт равный — **ничья**.
- Если в партии осталось меньше 3 игроков, она заканчивается досрочно.
