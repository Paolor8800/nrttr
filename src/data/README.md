# Банк вопросов

Вопросы лежат в `questions.ts`, в массиве `QUESTIONS`. Каждый вопрос:

```ts
{ id: 'q71', target: 'any', template: 'Чем {name} гордится больше всего?' },
```

- `id` — уникальный: `q` и следующий свободный номер. Номера удалённых вопросов не
  переиспользуйте.
- `target` — про кого вопрос: `'any'` — любой ведущий, `'male'` — только парень,
  `'female'` — только девушка.
- `template` — текст вопроса с подстановками:
  - `{name}` — имя ведущего;
  - `{м|ж}` — форма для парня и для девушки: `{один|одна}`, `{его|её}`,
    `{был|была}`. Внутри можно писать несколько слов: `{сам себе|сама себе}`.

## Правила, чтобы вопрос выглядел правильно

1. **Имя — в именительном падеже.** Имя подставляется как есть, поэтому
   «Какой любимый праздник у {name}?» превратится в «…у Настя?». Пишите так, чтобы
   имя было подлежащим: «Какой праздник {name} любит больше всего?». Если без
   косвенного падежа не обойтись: «{name}: какое у {него|неё} худшее качество?».
2. **В вопросах `'any'` всё, что зависит от пола, — через `{м|ж}`:**
   «Как ведёт себя {name}, когда {пьяный|пьяная}?».
3. В конце — `?` (или `.` для заданий), без пробела перед знаком препинания.
4. Не дублируйте вопросы: одинаковый текст в одной группе (парни / девушки) тест
   не пропустит.

После правок запустите `npm test`: тесты в `src/test/questions.test.ts` проверяют
уникальность, подстановки, пунктуацию, падеж имени и достаточный запас вопросов
для комнаты на 16 человек.
