# Система управления картами

## Текущая структура

Карты хранятся в файле `cards.ts` и управляются через систему `CardDeck` из `src/lib/cardDeck.ts`.

## Как работает система

### 1. CardDeck - умная колода
- **Автоматический ресброс**: Когда в колоде остается мало карт (< 20%), система автоматически перемешивает использованные карты обратно
- **Избегание повторов**: Последние 15-20 карт не попадают обратно в колоду сразу после ресброса
- **Fisher-Yates shuffle**: Настоящая случайная перемешка, не псевдослучайная

### 2. Два типа колод
- **Ответы** (answerCards): Буфер 15 недавних карт, ресброс при 20% остатка
- **Ситуации** (situationCards): Буфер 20 недавних карт, ресброс при 25% остатка

## Масштабирование до 1000+ карт

### Вариант 1: Один большой файл (рекомендуется для 1000 карт)
```typescript
// src/data/cards.ts
export const answerCards: string[] = [
  // ... 1000 карт
];
```

**Плюсы:**
- Простота
- Быстрая загрузка (все карты в памяти)
- Нет дополнительных запросов

**Минусы:**
- Большой файл (~100-200 KB)
- Все карты загружаются сразу

### Вариант 2: Разделение по категориям (для 1000+ карт)
```typescript
// src/data/answers/casual.ts
export const casualAnswers: string[] = [...];

// src/data/answers/spicy.ts
export const spicyAnswers: string[] = [...];

// src/data/cards.ts
import { casualAnswers } from './answers/casual';
import { spicyAnswers } from './answers/spicy';

export const answerCards = [...casualAnswers, ...spicyAnswers];
```

**Плюсы:**
- Организованность
- Легко добавлять новые категории
- Можно делать тематические паки

### Вариант 3: Lazy Loading (для 5000+ карт)
```typescript
// src/data/cardLoader.ts
export async function loadAnswerCards(): Promise<string[]> {
  const modules = await Promise.all([
    import('./answers/pack1'),
    import('./answers/pack2'),
    // ...
  ]);
  return modules.flatMap(m => m.default);
}
```

**Плюсы:**
- Минимальный начальный размер бандла
- Загрузка по требованию

**Минусы:**
- Сложность
- Задержка при первой загрузке

## Добавление новых карт

### Шаг 1: Добавьте карты в массив
```typescript
export const answerCards: string[] = [
  // ... существующие карты
  "Новая карта 1",
  "Новая карта 2",
  // ...
];
```

### Шаг 2: Система автоматически:
- ✅ Перемешает новые карты с существующими
- ✅ Будет избегать повторов
- ✅ Автоматически ресбросит колоду когда нужно

### Шаг 3: Никаких изменений в коде не требуется!

## Тестирование системы

Для проверки работы системы можно использовать:

```typescript
// В консоли браузера
const deck = new CardDeck(answerCards);
console.log(deck.getStats());
// { total: 1000, inDeck: 1000, inDiscard: 0, recentlyUsed: 0 }

const cards = deck.draw(100);
console.log(deck.getStats());
// { total: 1000, inDeck: 900, inDiscard: 100, recentlyUsed: 15 }
```
