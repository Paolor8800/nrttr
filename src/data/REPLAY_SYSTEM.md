# Система "Еще раз!" - Механика повторных игр

## Описание

Система позволяет игрокам играть несколько раундов подряд с одним и тем же составом, при этом карты из предыдущих игр исключаются из следующих игр в рамках одной сессии.

## Как это работает

### 1. Завершение игры
Когда игра заканчивается (один игрок остается с HP > 0), появляется экран Game Over с:
- Именем победителя
- Статистикой сессии (количество сыгранных игр, оставшиеся карты)
- Кнопкой "Еще раз!" (только для хоста)
- Кнопкой "На главную"

### 2. Нажатие "Еще раз!"
Когда хост нажимает кнопку "Еще раз!":

1. **Сбор использованных карт**:
   - Все карты из рук игроков
   - Все карты из колод (deck + discard pile)
   - Текущая ситуация
   - Опции ситуаций
   - Отправленные ответы

2. **Исключение карт**:
   - Собранные карты добавляются в глобальный пул исключенных карт сессии
   - `sessionExcludedAnswers` - все использованные карты ответов
   - `sessionExcludedSituations` - все использованные карты ситуаций

3. **Проверка достаточности карт**:
   ```
   Минимум для ответов: количество_игроков * 6 + 20 карт запаса
   Минимум для ситуаций: 12 карт (4 ситуации * 3 раунда)
   ```

4. **Создание новой игры**:
   - Создаются новые колоды БЕЗ исключенных карт
   - Всем игрокам восстанавливается HP до 100
   - Раздаются новые карты (6 на игрока)
   - Игра начинается с фазы `pickingSituation`
   - Счетчик `gamesPlayed` увеличивается на 1

### 3. Сброс сессии
Исключенные карты сбрасываются только когда:
- Игроки выходят из комнаты
- Создается новая комната
- Приложение перезагружается

## Технические детали

### Структура данных

```typescript
interface GameState {
  // ... другие поля
  sessionExcludedAnswers: string[];      // Все использованные ответы в сессии
  sessionExcludedSituations: string[];   // Все использованные ситуации в сессии
  gamesPlayed: number;                   // Счетчик игр в сессии
}
```

### Функция сбора карт

```typescript
function collectUsedCards(gameState: GameState): {
  usedAnswers: string[];
  usedSituations: string[];
}
```

Собирает все уникальные карты, которые были использованы в текущей игре.

### Проверка возможности рестарта

```typescript
function canStartNewGame(
  totalAnswers: number,
  totalSituations: number,
  excludedAnswers: string[],
  excludedSituations: string[],
  playerCount: number
): { canStart: boolean; reason?: string }
```

Проверяет, достаточно ли карт для новой игры.

## Примеры использования

### Сценарий 1: Обычная сессия
```
Игра 1: Используется 50 ответов, 10 ситуаций
  → Исключено: 50 ответов, 10 ситуаций
  → Осталось: 50 ответов, 90 ситуаций

Игра 2: Используется 48 ответов, 9 ситуаций (из оставшихся)
  → Исключено: 98 ответов, 19 ситуаций
  → Осталось: 2 ответа, 81 ситуация

Игра 3: Недостаточно карт ответов!
  → Кнопка "Еще раз!" недоступна
```

### Сценарий 2: Большая колода (1000 карт)
```
Игра 1: Используется 50 ответов, 10 ситуаций
  → Исключено: 50 ответов, 10 ситуаций
  → Осталось: 950 ответов, 990 ситуаций

Игра 2-19: По 50 ответов каждая
  → После 19 игр: Исключено ~950 ответов
  → Осталось: ~50 ответов

Игра 20: Недостаточно карт!
```

## Преимущества системы

1. **Уникальность**: Каждая игра в сессии использует новые карты
2. **Справедливость**: Все игроки видят разные комбинации
3. **Масштабируемость**: Система работает с любым количеством карт (100-10000+)
4. **Производительность**: Исключение карт происходит через Set для O(1) проверки
5. **Прозрачность**: Игроки видят статистику оставшихся карт

## Ограничения

1. **Минимум карт**: Нужно минимум `playerCount * 6 + 20` ответов и 12 ситуаций
2. **Память**: Все исключенные карты хранятся в памяти (для 1000 карт ~50KB)
3. **Только хост**: Только хост может запустить новую игру
4. **Один состав**: Нельзя добавить/удалить игроков между играми

## Будущие улучшения

### Возможные фичи:
1. **Режим "Бесконечная игра"**: Автоматический ресброс карт когда заканчиваются
2. **Статистика игрока**: Сколько раз выиграл в сессии
3. **Сохранение сессии**: Возможность продолжить сессию после перезагрузки
4. **Тематические паки**: Выбор категорий карт для сессии
5. **Настройка минимума**: Хост может настроить минимальное количество карт

## Заключение

Система "Еще раз!" обеспечивает уникальный игровой опыт в каждой игре сессии, исключая повторение карт и поддерживая справедливость для всех игроков. Система масштабируется от 100 до 10000+ карт без изменения кода.
